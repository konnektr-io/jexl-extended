# json

Parses a JSON string, or passes an already structured value straight through.

**Type:** transform

## Aliases

`toJson`, `parseJson`

## Parameters

- **input** (unknown): The JSON string to parse, or any already structured value.

## Returns

**Type:** `any`

The parsed JSON value, or the input unchanged when it is not a string.

## Examples

```javascript
toJson('{"key": "value"}') // { key: "value" }
```

```javascript
'{"name": "John", "age": 30}'|toJson // { name: "John", age: 30 }
```

```javascript
{ key: "value" }|toJson // { key: "value" }
```
