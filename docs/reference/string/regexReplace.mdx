# regexReplace

Replaces occurrences of a regular-expression pattern with a replacement string.

**Type:** transform

## Parameters

- **input** (unknown): The input string to perform replacements on.
- **pattern** (string): The regular expression source to search for. All occurrences are replaced.
- **replacement** (string): The replacement string; dollar patterns ($1, $&, …) are interpreted. Defaults to empty string.

## Returns

**Type:** `string`

The string with replacements made, or undefined if input is not a string.

## Examples

```javascript
regexReplace("a.b.c", ".", "-") // "-----"
```

```javascript
"a1b2c3"|regexReplace("[0-9]", "") // "abc"
```

```javascript
regexReplace("john smith", "(\\w+) (\\w+)", "$2 $1") // "smith john"
```
